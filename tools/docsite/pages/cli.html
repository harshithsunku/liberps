Commands

Command reference

The command layer turns text lines into configuration, operator commands and show views. erpsd, erpsctl and erps-sim all use it, and it embeds into any CLI.

Commands

Configuration keywords can be combined on one line. Durations take ms, s, m or h; a bare number is milliseconds. Blank lines and lines starting with # or ! are ignored.

CommandEffect
erps ring <name> ring-id <1-239> raps-vid <1-4094> port0 <port> port1 <port>Create or configure a ring instance
erps ring <name> role owner|neighbour|none [rpl-port <0|1>]RPL role of this node
erps ring <name> node-id <mac>|autoNode ID; auto takes the platform's system MAC
erps ring <name> mel <0-7> · pcp <0-7>Ring MEG level; 802.1Q priority of R-APS
erps ring <name> revertive|non-revertiveReversion mode (live)
erps ring <name> compat-version <1|2>Interworking with 2008-only nodes
erps ring <name> timers [wtr <dur>] [guard <dur>] [holdoff <dur>]WTR 1–12 min, guard 10 ms–2 s, hold-off 0–10 s (live)
erps ring <name> init-timer wtr|wtbOwner's timer at start-up; wtb converges faster after a cold start
erps ring <name> protected-vlans [add|remove] <list>VLANs the instance protects, e.g. 10-20,30
erps ring <name> sw-forwarding on|offForward R-APS between ring ports in software
erps ring <name> fop-pm on|off · fop-to on|off · fop-timeout <dur>Failure-of-protocol alarms
erps ring <name> relaxed-timers on|offAllow out-of-range timers (lab use)
erps ring <name> enable|disableStart or stop the instance; disable leaves both ring ports blocked
no erps ring <name>Delete a ring
erps ring <name> force-switch port <0|1>Operator forced switch
erps ring <name> manual-switch port <0|1>Operator manual switch
erps ring <name> clearClear a local FS or MS, or revert at the RPL owner
erps ring <name> flush-eventSend an R-APS flush event burst
show erps [summary] [json]One line per ring
show erps ring <name> [detail|status|config|counters|history] [json]Ring details
show running-config erpsThe configuration as commands
clear erps [ring <name>] countersReset counters
debug erps [ring <name>] level <error|warning|notice|info|debug|trace>Log level; debug logs every executed row

While a ring is enabled, timers and the revertive mode change live. Ports, role, ring ID and the other identity settings need disable first, and the command says so.

Configuration files

A configuration file is a command script, and show running-config erps prints one that recreates the current configuration exactly. Replaying it on a fresh instance produces the same running-config; a test checks that.

erps ring R1 ring-id 3 raps-vid 200 mel 5 port0 eth1 port1 eth2
erps ring R1 node-id 02:00:00:00:00:42
erps ring R1 role neighbour rpl-port 0
erps ring R1 timers wtr 7m guard 1s holdoff 300ms
erps ring R1 non-revertive
erps ring R1 protected-vlans 1-5,7,9-10
erps ring R1 sw-forwarding on
erps ring R1 enable
!

Long VLAN lists are split over several protected-vlans add lines so every line stays within the parser's limit.

Embedding the command layer

A host supplies the current time and, to create rings, a way to bind a ring to its dataplane. Everything else is in the library.

#include <erps/erps_cli.h>

erps_cli_platform_t p = {
    .ctx = my,
    .now = my_now,                    /* required */
    .port_lookup = my_port_lookup,    /* "eth1" -> handle (+ MAC); optional */
    .system_mac = my_system_mac,      /* for node-id auto; optional */
    .instance_bind = my_bind,         /* fill erps_ops_t + user for a ring being enabled */
    .instance_unbind = my_unbind,
};
erps_cli_t *cli = erps_cli_create(&p);
erps_cli_exec(cli, "erps ring R1 enable", out_fn, out_ctx);   /* errors print as "% ..." */

size_t n;
const erps_cli_cmd_t *cmds = erps_cli_commands(&n);   /* syntax + help, for host grammars */

instance_bind may adjust the configuration before the instance is created; the Linux platform uses this to turn on software R-APS forwarding and set port MACs. erps_cli_attach() exposes instances you created yourself to show and the operator commands.

Simulator commands

In erps-sim, every command above works on the rings n0…n<N-1>, plus these:

CommandEffect
sim create <nodes> [owner <n>] [no-neighbour] [non-revertive] [compat <1|2>] [wtr|guard|holdoff <dur>] [delay <us>] [jitter <us>] [loss <0..1>] [seed <n>] [id <node> <octet>]Build a ring and start every node
run <dur>Advance virtual time
link <i> down|up [cw|ccw]Fail or restore a link, both directions or one
node <i> down|upNode failure, and recovery as a fresh restart
node <i> fs <0|1> · ms <0|1> · clearOperator commands on a node
showOne-line ring summary, e.g. n2:B[-B] = Protection, port 1 blocked
events on|off · log <level>|offPrint protocol events or node logs
pcap <file>|offCapture all R-APS frames
expect state <node> <A-E> · expect blocked <node> <port> yes|no · expect no-loopsAssertions for scripts
