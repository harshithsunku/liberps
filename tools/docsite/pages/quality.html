How liberps is verified

Six kinds of evidence, each aimed at a different way an implementation of a ring protocol goes wrong: a row transcribed incorrectly, a scenario the spec describes, a race nobody thought of, malformed input, the real kernel, and a reader with fresh eyes.

Reproduce a failure

  • A chaos failure prints its seed and the command that replays it with the full event script and simulator log: ERPS_CHAOS_SEED0=<seed> ERPS_CHAOS_SEEDS=1 ERPS_CHAOS_VERBOSE=1 build/gcc/test-chaos.
  • Scenario tests log every simulator event with ERPS_TEST_LOG=4 and write a capture with ERPS_TEST_PCAP=file.pcap.
  • Fuzzer crashes are saved as fuzz-corpus/<target>-crash-*; run the target binary on that file to replay it.
  • On a live system, show erps ring <name> history lists the last 128 Table 10-2 rows executed, and debug erps level debug logs each one as it runs.
