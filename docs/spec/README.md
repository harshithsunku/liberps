# G.8032 reference material

- `NOTES.md` — our implementer's digest of ITU-T G.8032/Y.1344 (03/2020) for the single-ring scope: parameters and
  defaults, Table 10-1 / 10-2, actions, timers, flush logic, PDU layout, and liberps' interpretations. Committed.
- `G.8032-2020-03.txt`, `figures/` — the full text and figure pages of the Recommendation, regenerated locally
  from the ITU-T PDF with `python3 tools/extract_spec.py <pdf>`. They are © ITU, gitignored, and never committed.
  The PDF is freely available from the ITU-T website (Recommendation G.8032, edition 03/2020).
